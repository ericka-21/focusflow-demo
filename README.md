# FocusFlow

Demo de una pequeña aplicación de productividad construida con **HTML, CSS y JavaScript vanilla**. Está preparada para publicarse gratis en GitHub Pages.

## Características

- Crear tareas con prioridad alta, normal o baja.
- Marcar tareas como completadas o pendientes.
- Filtrar todas, pendientes y completadas.
- Eliminar tareas individuales o limpiar las completadas.
- Guardado automático en `localStorage` (los datos permanecen en el navegador).
- Diseño responsive para escritorio y móvil.
- Sin frameworks, backend ni proceso de compilación.

## Ejecutar

Abre `index.html` en tu navegador o utiliza un servidor local. Consulta [INSTALL.md](INSTALL.md) para instrucciones detalladas y publicación en GitHub Pages.

## Tecnologías

- HTML5
- CSS3
- JavaScript ES6+
- Web Storage API (`localStorage`)
